# Auth Service - Microservices Architecture

## Overview
Secure Authentication Service built for the college microservices project. Handles user registration, login, token issuance, and validation using Spring Security and JWT.

## Tech Stack
* Java 21
* Spring Boot
* Spring Security & JWT
* PostgreSQL & Spring Data JPA
* Maven

## APIs Provided
* `POST /register`
* `POST /login`
* `POST /logout`
* `GET /profile`
* `PUT /profile`
